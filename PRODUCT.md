## Platform

web

## Users

HATZ's website serves prospective franchise partners, global brand owners exploring emerging-market entry, and local stakeholders evaluating HATZ as a strategic partner. The primary user is a business decision-maker assessing HATZ's capability to bridge international brands into the Syrian and regional market.

## Product Purpose

HATZ redefines the retail landscape in emerging markets by forging robust strategic partnerships. The website communicates HATZ's role as a strategic bridge — connecting global innovations with promising local environments — and positions the Syrian market as a pivotal hub for future growth and regional expansion.

## Positioning

HATZ does more than transfer brands; it constructs the bridges through which global innovations cross to flourish within local markets. This "Cross-Border Connectivity" positioning, inspired by bridge engineering, is the core visual and strategic concept.

## Operating Context

The website is a corporate brand presence site (vCard/portfolio layout) built as a React/TypeScript clone of the PULSE academic template (reference: `seashell-seal-546316.hostingersite.com`). It will operate as a public-facing company site deployed via shared hosting with `.htaccess` rewrite rules.

## Capabilities and Constraints

- Built with React 19 + TypeScript + Vite 6
- Currently a clone of the PULSE WordPress/Elementor academic portfolio template
- Must be adapted to match HATZ brand identity while preserving the layout structure
- The reference site (`seashell-seal-546316.hostingersite.com`) is the source of truth for layout and behavior
- Responsive design across all device sizes
- Deployed via XAMPP locally, shared hosting in production

## Brand Commitments

### Name
HATZ

### Color Palette
- **Deep Teal / Green:** `#13544a` (Primary brand color)
- **Warm Copper / Brown:** `#a87143` (Secondary accent)
- **White:** `#ffffff`

### Typography
- **Primary English Font:** Montserrat (modern sans-serif)
  - Weights: Thin, ExtraLight, Light, Regular, Bold, Black
  - Generous uppercase letter spacing (tracking) for luxury and authority
- **Primary Arabic Font:** Montserrat-Arabic
  - Weights: ExtraLight, Light, Regular, Bold, Black

### Logo & Assets
- Logo components: Architectural icon (interlocked H, A, T, Z monogram) with clean horizontal/vertical wordmark configurations
- Configurations: Full Version, Horizontal Version, Vertical Version, Icon/Monogram Only
- Clear space rule: minimum space defined by unit dimension X (from component letter heights)
- Pattern applications: Repeating interconnected typography/monogram used as background graphics

### Visual Identity Concept
- Core Concept: "Cross-Border Connectivity"
- Design Inspiration: Bridge engineering
- Logo Structural Elements: Interconnected letters (seamless flow), clean perpendicular geometry (stability, trust, precision), elongated horizontal stroke (strategic bridge)

## Product Principles

1. **Cross-Border Connectivity** — Every design element should reinforce the bridge-building narrative between global brands and local markets
2. **Architectural Integrity** — Clean geometry, precision, and stability in layout and typography
3. **Professional Elegance** — Monochromatic palette with deep teal and warm copper accents, generous letter spacing, and minimal clutter
4. **Reference-True Behavior** — Layout interactions (scroll-based animations, project slider, timeline) must match the reference site exactly while wearing HATZ brand identity
5. **Responsive First** — The experience must be cohesive across desktop and mobile, reflecting the same brand quality

## Accessibility & Inclusion

The current implementation follows basic web standards. Future work should ensure adequate color contrast ratios with the established palette and maintain readable font sizing.
